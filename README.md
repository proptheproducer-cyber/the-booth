# The Booth

Voice to text and text to speech, in the browser. No install, no account, no keys.

- Hold Space or tap the mic to dictate. Tap to lock it hands free.
- Live caption, level meter, timer, word and character count.
- Copies to the clipboard automatically when you stop.
- Read any text back in a chosen voice, at a chosen speed.
- History is stored in your own browser. Nothing is uploaded here.

Speech recognition uses the browser's built in engine (Web Speech API),
which sends audio to Google in Chrome or Apple in Safari to transcribe it.
This site stores nothing and receives nothing.

Built for Creative Minds Collective.
